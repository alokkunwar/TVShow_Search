# TV Show Search

A modern **TV Show Search** app built with **HTML, JavaScript, Axios, and Tailwind CSS**, using the **TVMaze API**.  
Instantly search for TV shows and get details in a sleek, **Netflix-style** UI.

---

## Features

✅ **Live Search** – Get results as you type  
✅ **Lazy Loading** – Only loads images when they appear on screen  
✅ **Modern UI** – Fully responsive with **Tailwind CSS**  
✅ **Detailed Modal** – View show details, ratings, genres, and summary  
✅ **Official Links** – Direct links to show’s official website  
✅ **Dark Theme** – Looks clean and professional

---

## Installation & Setup

1. **Clone the repository**

   ```sh
   git clone https://github.com/alokkunwar/TVShow_Search.git
   cd tvshow_search

   ```

2. **Open index.html in your browser**

- No installation required! The project runs directly in the browser.
